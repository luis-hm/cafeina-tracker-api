Como executar — via agente

Peça ao agente (Codex) para executar o plano. Ele roda:

bash .spec/features/frontend-arquitetura/executar-tarefas.sh

Este arquivo é só visualização. Cada tarefa roda codex exec na árvore principal, uma após a outra, com contexto limpo e modelo/esforço já definidos. O gate final (verify + audit) roda sozinho; a execução fica em background e, a cada 1 minuto, o agente posta no chat a tabela de andamento (onp-spec resumo frontend-arquitetura --tabela) e o resumo geral de andamento (onp-spec resumo frontend-arquitetura).
